# Spatio-Temporal Analysis and Future Prediction of Urban Green Space Loss in Dhaka City (2000-2030)

## Research Questions

1. How did Dhaka's green space change from 2000 to 2025?
2. What is the relationship between green space and Land Surface Temperature?
3. What are the potential health and economic implications?
4. What is the predicted green space and heat scenario for 2030?

## Setup

Create and activate a virtual environment, then install the project dependencies:

```bash
python -m venv venv
```

Windows:

```bat
venv\Scripts\activate
```

macOS/Linux:

```bash
source venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```
